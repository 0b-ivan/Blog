# Kernel Notes Roadmap

Nur die größeren Sachen, die als Nächstes anstehen.

## Meilenstein 1 — Englische Version

- echte englische Artikel unter `/en/...`
- DE/EN-Umschalter pro Artikel
- UI-Texte ebenfalls auf Englisch
- Übersetzungen als eigene Markdown-Dateien in Git
- `hreflang` und eigener englischer RSS-Feed
- Smoke-Tests für beide Sprachen

## Meilenstein 2 — Semantische Suche

- DuckDB + lokales Embedding-Modell
- Kernel Grep unter `/grep`
- ähnliche Artikel in den Knowledge Graph übernehmen
- Neo4j später für echte Graph-Abfragen prüfen

Weitere Punkte kommen dazu, wenn sie konkret werden.
