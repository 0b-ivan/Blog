# Rive asset attribution

`liquid_download.riv` is the Rive "Liquid Download" example used for the reading-progress completion animation.

- Creator: Guido Rosso (`guidorosso`)
- Original Rive Marketplace project: https://rive.app/marketplace/1030-2020-liquid-download/
- Runtime asset source used here: https://github.com/rive-app/rive-flutter/blob/master/example/assets/liquid_download.riv
- License: Creative Commons Attribution (CC BY)

The browser runtime is provided by `@rive-app/canvas` and is self-hosted by Kernel Notes from the application image.
