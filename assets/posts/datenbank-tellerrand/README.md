# Bilder: Datenbank-Tellerrand

Die fünf SVG-Dateien sind eigene schematische Darstellungen mit erfundenen
Beispieldaten. Sie zeigen keine echten AWS-, Redis- oder MySQL-Oberflächen.
Die technische Einordnung folgt den im Artikel verlinkten offiziellen Quellen.

Die Titelgrafik liegt gemäß Cover-Konvention unter
`assets/covers/2026-10-23-nicht-alles-muss-in-mysql.svg`.
Alle sechs Grafiken sind unter CC0 freigegeben:
https://creativecommons.org/publicdomain/zero/1.0/

Herkunft und Lizenz sind zusätzlich unter
`datenbank-tellerrand-illustrations` in `posts/_sources.json` verzeichnet.
Die Photo Connection wird für diese eigenen SVG-Grafiken nicht verwendet:
Sie materialisiert fremde Commons-Rasterbilder und akzeptiert keine SVGs.

Die Pixabay-Cover-Vorschau wurde geprüft, kann lokal aber ohne
`PIXABAY_API_KEY` keine Kandidaten liefern. Die eigene Titelgrafik zeigt daher
konkret die fünf Datenmodelle; sie enthält weder Serverfotos noch Produktlogos.
Die Cover-CSS wurde mit der bestehenden `updateCoverStylesheet`-Funktion erzeugt.

Markdown verwendet normale root-relative Bildlinks ohne zusätzliche Syntax.
Die SVGs enthalten feste Seitenverhältnisse, Titel und Beschreibungen, keine
externen Ressourcen, Skripte oder eingebetteten Schriften. Damit folgen sie den
vorhandenen Artikelgrafiken und bleiben unabhängig von Drittservern darstellbar.
